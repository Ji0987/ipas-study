資料交換格式

格式特性
JSON鍵值對（{"temp": 25.3}），{ } 物件、[ ] 陣列、字串用雙引號；簡潔、體積小、多語言支援、任何文字編輯器可改；可表達層級（巢狀）結構；Web API 主流
XML以標籤表示，可表達層級但較冗長；MTConnect、SOAP 使用
CSV逗號分隔的平面表格，無法表達層級
Protobuf、MessagePack二進位格式，資料量小、省頻寬
⚠️
圖片、影片等二進位資料不適合放進 JSON（需 Base64，體積增加約 1/3），應存成檔案，JSON 只放路徑。MQTT 是協定不是格式；EDI 是企業間商業文件標準；HTML、DOC 不是開放資料的格式。

Web 服務與即時呈現

  • RESTful API：URI 表示資源，GET 查詢、POST 新增、PUT 更新、DELETE 刪除（沒有 QUERY）；優點是簡單、可擴展、跨平台，安全性要另外處理。GET 參數在網址上，不可傳機敏資料。
  • WoT（Web of Things）：以 URL 表示裝置，用網頁技術開發。
  • 網頁即時更新數據：WebSocket（持續雙向連線，伺服器負擔最小）＞ Long Polling ＞ AJAX（只更新局部資料）＞ 整頁重新載入（延遲最大、體驗最差）。WebSocket 本身不加密，要用 wss://。
  • 傳感資料最常用 MQTT（發布／訂閱、非同步、低頻寬、QoS、斷線重連，適合網路品質差時）；也常用 HTTP、AMQP。MQTT 與 CoAP 的標頭都是二進位格式；HTTP 沒有 QoS 等級。

資料庫

關聯式（SQL）
  • 結構化資料、預先定義資料表
  • ACID 交易
  • SQL Server、Oracle、MySQL、MariaDB、PostgreSQL、SQLite
NoSQL（Not Only SQL）
  • 非結構、半結構資料，鬆散樹狀結構（概念源自 Lotus Notes）
  • 水平擴充，多採 BASE（最終一致性）；部分也支援交易
  • 鍵值（Redis）、文件（MongoDB，存 JSON，可建索引）、欄族（HBase、Cassandra）、圖形（Neo4j）
  • 觸發程序（TRIGGER）：資料變動時依條件自動執行動作。
  • 複寫（Replication）：多份複本放不同主機，故障時可還原，恢復最快；分片（Sharding）：資料切分到多台主機，水平擴展。
  • 記憶體快取：加速存取、需叢集擴展與一致性雜湊，不負責永續儲存。
  • NAS：資料不必依附在某台伺服器，多台裝置共用。
  • 大量資料流程：Device → Access Server → Message Queue → NoSQL，以訊息佇列緩衝尖峰。

雲端服務與平台

模式例子
IaaS：虛擬機、儲存、網路EC2、GCP Compute Engine、Azure VM、Hicloud 租用主機
PaaS：開發與執行平台Google App Engine、Heroku（GCP 以 IaaS＋PaaS 為主）
SaaS：直接用的軟體Gmail、Google Docs、Google Meet、雲端儲存；自己開發給使用者用的服務
  • 金字塔由上而下：SaaS → PaaS → IaaS。雲端特性：隨時存取、可量測、資源池共享、以虛擬化為基礎。
  • 公有雲：多家公司共用平台、業者維運、受法規限制（感測器不能直接上雲，需閘道器）；私有雲：自行維運，外部以 VPN 連入，仍有資安風險；混合雲：機敏資料自管、尖峰借用公有雲。
  • Docker：作業系統等級虛擬化、容器共用主機核心（不必各裝 OS）、輕量、可安裝在 Linux／Windows／macOS；元件有 client、daemon、libcontainer、image。
  • 虛擬化效能受硬碟速度、記憶體、CPU 影響，儲存空間大小影響不大；網路虛擬化可讓同一台主機的虛擬機分別接內外網。
  • 雲平台功能：收集、儲存、查詢、分析、數據變更通知、裝置認證與身分識別、OTA 更新；裝置主動上傳、平台接收；不負責開發裝置與近端通訊。
  • 物聯網雲平台：AWS IoT Core、Azure IoT Hub、GCP；IBM Cloud 是整體平台名稱；MediaTek LinkIt 是開發板。
  • 設計考量：自動延展、線性擴展的儲存、快取、資料分散備份（不是集中）、即時部署；最重要的是數據傳輸速度。開放原始碼是為了降低成本，不是提高門檻。

資料分析與視覺化

  • 資料視覺化的目的是提高理解與決策能力：折線圖看隨時間的變化（鍋爐溫度）、柱狀圖比較類別、圓餅圖看比例、散點圖看關係、樹狀圖看階層；心智圖不是數據視覺化。
  • 時間序列分析、傅立葉轉換、神經網路（LSTM）處理時序資料。
  • NoSQL 分散式分析以 <Key, Value> 分類與建立關聯（MapReduce）；Spark 用記憶體運算，比 Hadoop MapReduce 快。
  • 資料分析可發掘商機、偵測異常、找出客戶需求；開放資料（Open Data）可補充自建感測資料，格式為 CSV、JSON、XML；須考慮隱私（個人報稅資料不會開放）。
  • 嵌入式 Linux 空間不足時，Shell Script 不需額外安裝執行環境。

開源軟體與授權

類別原始碼特性
自由軟體（Free Software）公開使用、研究、散布、改良（含散布改良版）四大自由；以 GPL 授權，仍有著作權
開源軟體公開可商用、不一定免費；不能要求一起散佈的其他軟體也開源
公共領域軟體—放棄著作權
免費軟體（Freeware）通常不公開免費使用、作者保留著作權
共享軟體（Shareware）不公開試用期或功能限制；版權屬原作者，不可破解、改作販售
授權要求
GPLCopyleft（標誌是反寫的 C），衍生作品必須以 GPL 開源，不能改成閉源；要求最嚴格
LGPL以動態連結呼叫函式庫不視為衍生作品，私有軟體可使用
BSD、MIT寬鬆：保留版權聲明即可，可閉源商用
Apache寬鬆，可再發佈為開源或商業軟體；商標（羽毛、Tomcat 貓）另需書面授權
雙重授權（MySQL）選 GPL 免費但受 GPL 規範；選商業授權要付費、不受 GPL 規範

基於開源軟體開發不需徵得原作者同意，但要保留著作權聲明；開源軟體也必須遵守授權。常見開源軟體：Linux、Apache、MySQL、vim、Eclipse、FileZilla；Microsoft Office、IIS 不是。
